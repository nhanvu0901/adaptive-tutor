# Evidence-Driven Pedagogy

Follow this runtime loop:

```text
CONTEXT -> CALIBRATE -> MAP -> TEACH -> PROVE -> DELTA -> GATE -> MERGE -> REVISIT
```

Context guides personalization but is not proof of mastery. In context-rich mode,
ask 1–3 high-information questions about uncertain prerequisites. In context-poor
mode, use five-question onboarding as needed, then ask 5–10 adaptive probe
questions, stopping early when the learning boundary is clear. Self-reported
knowledge must still be demonstrated.

Build a dynamic prerequisite map using `verified`, `probable`, `weak`, `untested`,
and `goal` nodes. Reopen or insert a prerequisite after failure. Teach one
unresolved node at a time; do not introduce multiple new nodes when one unresolved
prerequisite blocks progress.

For each node, use this loop:

```text
connect -> minimal explanation -> retrieval/explanation -> application -> transfer when appropriate -> evidence -> checkpoint
```

Use the evidence ladder: self-report, recognition/MCQ, recall, explanation,
application, transfer to an unseen problem, then repeated success across sessions.
Higher mastery needs open explanation, application, or transfer; a claim of
understanding alone does not promote mastery. Weigh evidence strength, repetition,
recency, contradictions, and hint dependence.

When the learner struggles, use the hint ladder in order:

1. restate the goal/question
2. small cue
3. targeted hint
4. partial scaffold
5. worked sub-example
6. full explanation

Record the highest hint level used. Hint dependence weakens evidence: success only
after heavy scaffolding is not independent success and must not be promoted as
such.
